# Product

## Platform

web

## Stack

React 18 + Tailwind CSS + Framer Motion + Lucide React + Supabase Auth + FastAPI + Razorpay

## Users

Individuals and households seeking a frictionless, culturally resonant daily micro-savings mechanism ("Kudam") to build wealth incrementally.

## Product Purpose

Meenamma digitizes traditional Tamil micro-savings rituals. Users select a daily step amount (e.g. ₹1, ₹5, ₹10) which accumulates seamlessly and settles on a weekly or monthly cadence via automated payment mandates.

## Positioning

The world's first South-Asian Neo-Traditional micro-savings platform combining ancient Tamil heritage (Kudam savings ceremony) with modern fintech precision, high-touch micro-interactions, and automated bank sweeps.

## Operating Context

Web and mobile browsers, fast mobile-first interaction, daily check-in rituals, and automated periodic settlement.

## Capabilities and Constraints

- Daily step savings configuration (₹1 to ₹100/day)
- Automated settlement via Razorpay UPI mandates or manual ceremony settlement
- Supabase Auth with Google OAuth and Email integration
- Live savings calculator and visual Kudam Mandala progress
- Neo-traditional Tamil typography ("மீ") and rich micro-interactions

## Brand Commitments

- Name: Meenamma (மீனம்மை / மீ)
- Aesthetic: Cyberpunk / South-Asian Neo-Traditional (neon gold, obsidian canvas, translucent glassmorphism, interactive kudam mandala)
- Tone: Empowering, auspicious, precise, culturally grounded yet futuristic
